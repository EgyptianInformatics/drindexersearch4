Search / Home

Search is the product's primary task. The database identity, active scope, result type and search engine mode are visible without consuming much vertical space.

Core UX rules

  • Search works across all scans by default.
  • Paths are visible in fast results, because knowing where a file lives is the point of the app.
  • Folders are first-class results, not an advanced hidden mode.
  • Browse and Search share the same mental model: Archive → Scan → Root → Folder.
  • Database import is staged and atomic.

Proposed data support

Mobile export schema v3 keeps backward compatibility with v2 but adds explicit roots, folder ownership/parent relationships and exact byte sizes. This eliminates repeated tree reconstruction and removes ambiguous inferred roots.
